1
Open Wikipedia Page
OPEN PAGE
Navigates to the Wikipedia page containing the FIFA World Cup finals table. This step initializes the RPA browser session.
⬇ INPUT — PAGE URL
https://en.wikipedia.org/wiki/List_of_FIFA_World_Cup_finals
⬆ OUTPUT
Wikipedia page loaded in browser session. The "List of FIFA World Cup finals" table is now accessible in the DOM.
2
Loop Through First 10 Table Rows
LOOP
Iterates 10 times (once per table row). The index variable i runs from 1 to 10. Inside the loop, each iteration extracts one row of data and appends it to Google Sheets.
⬇ INPUT — ITERATIONS
10
⬆ OUTPUT — INDEX VARIABLE
i = 1, 2, 3 … 10
(used to target table rows)
📝 NOTE
Index starts from 1. In the DOM selector, we use tr:nth-child(i+1) because tr:nth-child(1) is the header row.
⟳ LOOP BODY — Repeats 10×
2.1
Extract Year
EXTRACT HTML
Extracts the year value from the first column of the current table row.
⬇ INPUT — ELEMENT DOM PATH
#mw-content-text > div.mw-parser-output > table.wikitable.sortable > tbody > tr:nth-child({i+1}) > th > a
⬆ OUTPUT — EXTRACTED TEXT
Year string → e.g. "1930", "1934", … "1974"
2.2
Extract Winner
EXTRACT HTML
Extracts the winning country name from the second column (Winners) of the current row.
⬇ INPUT — ELEMENT DOM PATH
#mw-content-text > div.mw-parser-output > table.wikitable.sortable > tbody > tr:nth-child({i+1}) > td:nth-child(2) > span > a
⬆ OUTPUT — EXTRACTED TEXT
Winner country name → e.g. "Uruguay", "Italy", "Brazil"
2.3
Extract Score
EXTRACT HTML
Extracts the final match score from the third column (Score) of the current row.
⬇ INPUT — ELEMENT DOM PATH
#mw-content-text > div.mw-parser-output > table.wikitable.sortable > tbody > tr:nth-child({i+1}) > td:nth-child(3) > a
⬆ OUTPUT — EXTRACTED TEXT
Score string → e.g. "4–2", "2–1", "5–2"
2.4
Extract Runners-up
EXTRACT HTML
Extracts the runners-up country name from the fourth column (Runners-up) of the current row.
⬇ INPUT — ELEMENT DOM PATH
#mw-content-text > div.mw-parser-output > table.wikitable.sortable > tbody > tr:nth-child({i+1}) > td:nth-child(4) > span > a
⬆ OUTPUT — EXTRACTED TEXT
Runners-up country name → e.g. "Argentina", "Hungary", "Sweden"
2.5
Append Row to Google Sheets
CALL API
Makes a POST request to the Google Sheets API to append the extracted row data. This is configured the same way as a Postman call.
🔗 METHOD & URL
POST https://sheets.googleapis.com/v4/spreadsheets/{SPREADSHEET_ID}/values/Sheet1!A:D:append
⚙ QUERY PARAMETER 1
valueInputOption = USER_ENTERED
⚙ QUERY PARAMETER 2
insertDataOption = INSERT_ROWS
📋 HEADER 1
Authorization
Bearer {ACCESS_TOKEN}
📋 HEADER 2
Content-Type
application/json
📦 REQUEST BODY (JSON)
// Variables are from Steps 2.1–2.4 { "range": "Sheet1!A:D", "majorDimension": "ROWS", "values": [ [ "{year}", "{winner}", "{score}", "{runner_up}" ] ] }
✅ EXAMPLE — ITERATION 1 BODY
{ "range": "Sheet1!A:D", "majorDimension": "ROWS", "values": [ ["1930", "Uruguay", "4–2", "Argentina"] ] }
↩ Repeat for next i (until i = 10)
✓
Workflow Complete
END
All 10 rows have been extracted from Wikipedia and appended to the Google Sheet. The sheet now contains the Year, Winner, Score, and Runners-up for the first 10 FIFA World Cup finals (1930–1974).
